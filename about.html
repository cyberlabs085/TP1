TP1

Ce TP porte sur les bases de HTML et CSS. Nous allons créer une page web simple pour pratiquer les concepts fondamentaux du développement web.

Objectifs du TP

  • Apprendre à structurer une page HTML avec des éléments de base.
  • Utiliser les balises HTML pour organiser le contenu.
  • Appliquer des styles CSS pour améliorer l'apparence de la page.

Contenu du TP

Le TP se compose de plusieurs sections, chacune abordant un aspect différent du développement web :

  1. Structure HTML : Apprendre à utiliser les balises de base telles que <div>, <h1>, <p>, etc.
  2. Styles CSS : Appliquer des styles pour changer les couleurs, les polices, et la mise en page de la page.
  3. Responsive Design : Rendre la page adaptable à différents appareils et tailles d'écran.
